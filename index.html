Features

Why Wiztri?

Built to find what is eating your disk space — fast, and without the hassle.

⚡

Fast MFT scan

Raw $MFT reading (Rust) scans a drive in seconds — far faster than a normal walk.

◫

Treemap & table

Size proportions visualized as a squarified treemap, alongside a sortable table (Size / Allocated).

💽

Drive dropdown

Pick drive A:–Z: straight from the dropdown — no path typing.

📂

Open in Explorer

One click (↗) to open a folder or file in Windows Explorer.

🛡

System markers

Hidden/system folders, symlinks/junctions, and access errors are clearly flagged.

🔌

Offline & private

Your data never leaves the computer. No account, no cloud.

How to use

Get started in 3 steps

As simple as running the installer and pressing Scan.

Download & install

Run wiztri.setup.exe and follow the installer (NSIS).

Run as Administrator

Right-click → Run as administrator to enable the fast MFT scan mode.

Pick a drive & Scan

Select a drive from the dropdown, press Scan, then explore the results.
